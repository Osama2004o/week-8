## `dir 2` — Agentic Hybrid RAG

A FastAPI platform that answers questions over ingested documents using three specialized agents — **Retriever → Analyst → Answer** — coordinated by an Orchestrator. Retrieval combines ChromaDB semantic search with BM25 keyword search, cross-encoder reranking, and context selection. Answers are validated against retrieved evidence IDs before citations are emitted.

Highlights:

- **Hybrid retrieval** with query rewriting, metadata filtering, and reranking.
- **Adaptive evidence gathering** — the Analyst can request additional retrieval passes.
- **Verifiable citations** — unverifiable citation drafts are rejected rather than presented as sourced.
- **Multi-format ingestion** — PDF, DOCX, TXT, PPTX, WAV, source code, web pages, Wikipedia, and OCR images.
- **Voice interface** — Groq Whisper (`whisper-large-v3-turbo`) transcription with Faster-Whisper fallback.
- **PDF reports** — generated by a dedicated Report Generator Agent.
- **Infrastructure as Code** — Terraform modules for a future AWS deployment (ECS Fargate, EFS, S3, ElastiCache Redis, Secrets Manager).

### Quick Start

```bash
cd "dir 2"
python -m venv .venv
.\.venv\Scripts\Activate.ps1        # Windows PowerShell
pip install -r requirements.txt
copy .env.example .env              # add OPENROUTER_API_KEY
python main.py
```

Open the web UI at [http://localhost:8000/](http://localhost:8000/) or the Swagger docs at [http://localhost:8000/docs](http://localhost:8000/docs).
